The pipeline

How the pieces fit together

01 · Observe

Consent-based browser metadata or authorized Windows network flows.

02 · Describe

NoHackFlow v1 extracts 33 structured connection features.

03 · Analyze

Verified local model bundles can produce flow-level assessments.

04 · Explain

Show assessment state, risk index and clear limitations.

What has been built

Project components

01

Chrome extension MVP

On-device browser signals, opt-in local history, clear privacy controls and an optional Windows companion panel.

02

Windows flow pipeline

Scapy/Npcap capture, deterministic replay, feature contract validation and bounded SQLite observations.

03

Hybrid ML code

Gradient boosting, anomaly signals and leakage-aware stacking. Real dataset training and external validation are still required.

04

Local model bridge

The interface distinguishes companion availability from model availability. Unavailable models do not create invented alerts.

05

Data science learning

Progressive notebooks for auditing data, exploring features, splitting groups, baselines and reproducible training.

06

Engineering discipline

Automated Linux/Windows checks, privacy boundaries, artifact integrity and transparent known limitations.
